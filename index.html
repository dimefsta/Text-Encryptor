CipherVault User Guide & Security

⚡ Quick Start

  1. Choose an Algorithm: Select an encryption or encoding scheme from the dropdown.
  2. Enter Parameters: For AES, Vigenère, or XOR, provide a key (or click Generate). For Caesar, adjust the shift slider.
  3. Input Text & Transform: Type or paste your message (or drag and drop a .txt file), then click Encrypt or Decrypt.
  4. Copy or Download: Use the one-click copy button or download your result directly to a text file.

🛡️ Encryption vs. Encoding (Important!)

Encryption protects confidentiality using a secret key. Without the key, the ciphertext cannot be read (e.g. AES-256).

Encoding (e.g., Base64, Hex, URL) is designed for data representation and safe transmission over text protocols. It provides zero security against unauthorized access.

🔒 Privacy Guarantee

All operations are processed strictly in your web browser using standard JavaScript and the browser's native Web Cryptography API (window.crypto.subtle). Your plaintexts, passwords, and keys are never transmitted to any external server or stored anywhere.
